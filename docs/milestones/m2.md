# Milestone M2 — Pós-M1 (v0.9)

Plano da milestone em execução. Não é spec: o comportamento atual mora em [`specs/`](../specs/kanji.md). Fontes: [`prd.md`](../prd.md), [`roadmap.md`](../roadmap.md), specs citadas, [`processo.md`](../processo.md) etapa 2, issues [#58](https://github.com/murilinhoPs/MangaJP/issues/58) e [#59](https://github.com/murilinhoPs/MangaJP/issues/59), PR [#88](https://github.com/murilinhoPs/MangaJP/pull/88) (aberto). O que não está fechado nessas fontes vira questão numerada, sem inventar produto.

## 1. Objetivo

Entregar os Should que faltavam depois do MVP: kanji no Caderno (fora do SRS), Cloud Vision opcional atrás de toggle, histórico `/pages`, overlay de bounding boxes, suspender no Deck e backup JSON do Caderno + SRS. A M2.1 (iOS secundário) já está na `main`; esta milestone não reabre F40. Saída esperada: o loop de estudo do M1 continua, e cada feature deste doc tem critério de aceite verificável no app, nos dados e nos testes.

## 2. Escopo

### F24 + F45 — KANJIDIC2 no lookup e Salvar kanji

Kanji tocado na ficha da palavra abre a ficha do kanji (on/kun, significados, traços) a partir da tabela `kanji` do `jmdict.sqlite`. **Salvar kanji** grava `saved_kanji` e o Caderno ganha a aba **Kanji**. Sem nota, sem card, fora do SRS.

- **Área:** `dictionary`.
- **Spec:** [`kanji.md`](../specs/kanji.md) (fechada); [`dicionario.md`](../specs/dicionario.md); [`caderno.md`](../specs/caderno.md).
- **Dependências:** issue [#58](https://github.com/murilinhoPs/MangaJP/issues/58); implementação no PR [#88](https://github.com/murilinhoPs/MangaJP/pull/88) (`schemaVersion` 8→9). F24 e F45 entram no mesmo PR.
- **Estado:** spec na `main`; código ainda não squash-mergeado.

### F26 — Cloud Vision opcional

Motor `OcrEngine` extra: Cloud Vision `DOCUMENT_TEXT_DETECTION` com `languageHints: ["ja"]`. Só com o toggle «Usar OCR na nuvem» em Ajustes. Chave não embutida. Não é o default (ADR-0001: manga-ocr 20,75% CER vs Vision 44,53% no GT kanji). Filtro de ruby unofficial não é default. ML Kit não entra.

- **Área:** `ocr`.
- **Spec:** [`ocr.md`](../specs/ocr.md); [`settings.md`](../specs/settings.md); [ADR-0001](../adr/0001-ocr-default-manga-ocr.md).
- **Dependências:** issue [#59](https://github.com/murilinhoPs/MangaJP/issues/59). Ordem depois da [#58](https://github.com/murilinhoPs/MangaJP/issues/58), sem dependência de código. Q-N3 (orçamento USD/mês) aberta e não bloqueante.
- **Estado:** issue aberta; várias questões de produto ainda sem decisão (seção 7).

### F21 — Lista `/pages` (histórico)

- **Área:** `capture`.

### F23 — Suspender e reativar no Deck

- **Área:** `review`.

- **Área:** `platform`.

- **Dependências:** F45 / schema 9 (`saved_kanji`), por isso entra depois da [#58](https://github.com/murilinhoPs/MangaJP/issues/58). Restore de backup *anterior* ao #88 (sem `saved_kanji`) continua critério de aceite. Formato exato do JSON e se o restore substitui ou mescla não estão fechados (Q6, Q7).
- **Estado:** sem issue.

- **Testes / prints:** domínio + widget 390×844 e ≥900; prints da aba, do vazio e da ficha com **Salvar kanji**, no head do PR da [#58](https://github.com/murilinhoPs/MangaJP/issues/58).

### F25 — backup JSON

O arquivo de backup é JSON, **com a versão do schema Drift gravada no arquivo**, e inclui as linhas de `saved_kanji` no schema 9 do [#88](https://github.com/murilinhoPs/MangaJP/pull/88) (`literal`, `saved_at`, `origin_page_id` que pode ser `null`). Zip de imagens continua opcional e separado. Export SQLite: Q6.

- **AC-backup-export:** exportar produz um JSON que declara a versão do schema e contém Caderno + SRS + `saved_kanji` (vazio se não houver kanji salvo).
- **AC-backup-roundtrip:** restaurar um backup da versão corrente devolve as mesmas palavras, cards/SRS e kanji salvos (round-trip). Substitui vs. mescla: Q7.
- **AC-backup-old-schema:** restaurar um backup de versão **anterior** do schema funciona. Exemplo: backup feito antes do [#88](https://github.com/murilinhoPs/MangaJP/pull/88), schema 8, **sem** `saved_kanji` — o restore conclui; Caderno + SRS voltam; a aba Kanji fica vazia, sem erro.
- **AC-backup-origin-page:** restaurar kanji com `origin_page_id` `null`, ou apontando para página que não existe no destino, **não perde o kanji**. A linha entra em `saved_kanji`; `origin_page_id` fica `null` se a página não existir.
- **AC-backup-unknown-schema:** um backup com versão de schema **desconhecida ou mais nova** do que o app que restaura é **recusado** com mensagem clara. **Nada é gravado** (nem Caderno, nem SRS, nem `saved_kanji`, nem zip).
- **Testes / prints:** testes de domínio cobrindo os cinco ACs (fixture schema 8 sem `saved_kanji`; schema 9 com `origin_page_id` null e com id inexistente; schema futuro recusado e assert de que o banco não mudou). Widget/prints de Ajustes: export, restore ok, restore recusado (mensagem visível), 390×844 e ≥900. Sem chave, token ou path pessoal no JSON de fixture nem nos prints.

## 6. Riscos

- **Cloud Vision (custo e chave).** Bake-off pior que manga-ocr; cada chamada paga. Chave mal guardada vaza. Mitigação já na spec: toggle off por default, chave não embutida, NF6. Q-N3 e Q8–Q11 ainda abertas.
- **Desenho das bounding boxes (F22).** Muitas boxes numa página ~2 MP podem atrasar o overlay no telefone. Mitigação: medir no widget/emulador 390×844 antes do squash; se passar de NF2, reduzir trabalho no overlay no mesmo PR, sem mudar o contrato de `blocks`.
- **Backup JSON: versão do schema e migração (F25).** Restore de schema antigo (sem `saved_kanji`) tem de funcionar; `origin_page_id` null ou página ausente não pode descartar o kanji; schema desconhecido/mais novo tem de abortar sem escrever. Um restore que misture esses casos sem os ACs da seção 4 corrompe o Caderno ou perde kanji. Mitigação: testes de domínio nos três casos **antes** do print; recusa sem gravar nada.
- **iOS / macOS com Mac offline.** Prints e parte da suíte dependem do worker Mac. A fila [#54](https://github.com/murilinhoPs/MangaJP/issues/54) não bloqueia o merge na nuvem; o item tem de existir **antes** do review, com o link no PR.

## 7. Questões em aberto

Cada item espera o dono do projeto. Default sugerido só para destravar implementação; não é decisão até o ok.

1. **F21 — conteúdo da lista `/pages` além do thumbnail.** A spec pede histórico com thumbnails e não fecha título, data nem badges. **Default sugerido:** thumbnail + título da página (quando houver) + data; sem badges de `word_state` nesta entrega.
2. **F21 — empty state e relação com Capturas recentes.** **Default sugerido:** Capturas recentes na Home permanecem; `/pages` é o histórico completo. Lista vazia: copy no padrão das outras listas («Nenhuma página.» / ação para galeria), fechado no PR da feature.
3. **F22 — quando o overlay liga.** Spec: «quando o OCR fornecer». Não diz se há toggle. **Default sugerido:** overlay visível quando houver `Rect`; controle na tela do leitor para esconder. Pode precisar de design (motif) antes do código.
4. **F22 — tap na box.** **Default sugerido:** o mesmo lookup do tap no texto da página. Sem ação extra nesta entrega.
5. **F23 — onde suspender/reativar no Deck.** Modelo de dados fechado; UI não. **Default sugerido:** ação na lista ou no detalhe do card, sem diálogo extra além do padrão de confirmação já usado no Deck.
6. **F25 — formato do JSON além da versão do schema e de `saved_kanji`.** PRD fala em «export JSON/SQLite»; settings.md só JSON + zip opcional de imagens. **Default sugerido:** um arquivo JSON com a versão do schema Drift e as tabelas do Caderno + SRS + `saved_kanji`; zip de imagens opcional e separado; **sem** export SQLite nesta entrega.
7. **F25 — restore substitui ou mescla.** **Default sugerido:** restore substitui Caderno + SRS + `saved_kanji` do aparelho, depois de confirmação explícita. Schema desconhecido/mais novo **não** grava nada (já é AC).
8. **F26 — quando o Cloud Vision entra.** A spec chama de «fallback» e não define se é só o toggle, se dispara na falha do manga-ocr ou por crop. **Default sugerido:** engine escolhida pelo toggle, atrás de `OcrEngine`; **não** fallback automático.
9. **F26 — como a chave é fornecida e guardada.** Só está definido «não embutida». **Default sugerido:** campo em Ajustes, persistida localmente, nunca no binário nem no git. Prints que mostrem a chave usam valor fake e, se necessário, borrão declarado.
10. **F26 — sem rede com o toggle ligado.** **Default sugerido:** erro visível; não cai para manga-ocr; não enfileira.
11. **Q-N3 — orçamento Cloud Vision (USD/mês).** Aberta no PRD, não bloqueante. **Default sugerido para a M2:** sem limite nem contagem de chamadas no app nesta entrega; a questão do PRD permanece aberta.
12. **F26 — critério de sucesso em CER.** Nenhuma fonte define meta para o Vision no app. **Default sugerido:** nenhuma meta de CER nesta entrega; default continua manga-ocr. Trocar o default exige ADR nova (ADR-0001).
13. **F29 no picker de OCR em Ajustes.** settings.md pendente. **Default sugerido:** F29 fora da M2; o picker desta entrega só lista manga-ocr e Cloud Vision.
14. **F38 — proposta de revisar kanji em avaliação.** Specs registram «futuro pós-v1: cards a partir de `saved_kanji`». **Sem default.** Não há decisão; F38 permanece Won't.
