# Milestone M2 — Pós-M1 (v0.9)

Plano da milestone em execução. Não é spec: o comportamento atual mora em [`specs/`](../specs/kanji.md). Fontes: [`prd.md`](../prd.md), [`roadmap.md`](../roadmap.md), specs citadas, [`processo.md`](../processo.md) etapa 2, issues [#58](https://github.com/murilinhoPs/MangaJP/issues/58) e [#59](https://github.com/murilinhoPs/MangaJP/issues/59), PR [#88](https://github.com/murilinhoPs/MangaJP/pull/88) (squash `70d150d`, fechou a #58). ## 1. Objetivo

Entregar os Should que faltavam depois do MVP: kanji no Caderno (fora do SRS), Cloud Vision opcional atrás de toggle, histórico `/pages`, overlay de bounding boxes, suspender no Deck e backup JSON do Caderno + SRS. A M2.1 (iOS secundário) já está na `main`; esta milestone não reabre F40. Saída esperada: o loop de estudo do M1 continua, e cada feature deste doc tem critério de aceite verificável no app, nos dados e nos testes.

### F25 — backup JSON

O arquivo de backup é JSON, **com a versão do schema Drift gravada no arquivo**, e inclui as linhas de `saved_kanji` no schema 9 do [#88](https://github.com/murilinhoPs/MangaJP/pull/88) (`literal`, `saved_at`, `origin_page_id` que pode ser `null`). Zip de imagens continua opcional e separado. Export SQLite: Q6.

- **AC-backup-export:** exportar produz um JSON que declara a versão do schema e contém Caderno + SRS + `saved_kanji` (vazio se não houver kanji salvo).
- **AC-backup-roundtrip:** restaurar um backup da versão corrente devolve as mesmas palavras, cards/SRS e kanji salvos (round-trip). Substitui vs. mescla: Q7.
- **AC-backup-old-schema:** restaurar um backup de versão **anterior** do schema funciona. Exemplo: backup feito antes do [#88](https://github.com/murilinhoPs/MangaJP/pull/88), schema 8, **sem** `saved_kanji` — o restore conclui; Caderno + SRS voltam; a aba Kanji fica vazia, sem erro.
- **AC-backup-origin-page:** restaurar kanji com `origin_page_id` `null`, ou apontando para página que não existe no destino, **não perde o kanji**. A linha entra em `saved_kanji`; `origin_page_id` fica `null` se a página não existir.
- **AC-backup-unknown-schema:** um backup com versão de schema **desconhecida ou mais nova** do que o app que restaura é **recusado** com mensagem clara. **Nada é gravado** (nem Caderno, nem SRS, nem `saved_kanji`, nem zip).
- **AC-backup-atomic:** restore é atômico (uma transação). Se falhar no meio, **nada** é gravado.
- **AC-backup-normalize:** cada `literal` de `saved_kanji` passa por `normalizeKanjiLiteral` (strip de IVS/VS, exatamente 1 code point). Literal inválido **não entra**; o restore dos demais continua; a UI mostra quantos foram pulados.
- **AC-kanjidic-attr** (dono deste PR de feature): seção Sobre / Fontes **dentro de `/settings`** (sem rota nova) mostra «KANJIDIC2 © EDRDG, CC BY-SA 4.0» com link da EDRDG.
- **Testes / prints:** testes de domínio cobrindo os cinco ACs acima (export, round-trip, schema antigo, `origin_page_id` órfão, schema desconhecido) **e** os dois de robustez (atômico + `normalizeKanjiLiteral`). Fixtures: schema 8 sem `saved_kanji`; schema 9 com `origin_page_id` null e com id inexistente; schema futuro recusado e assert de que o banco não mudou; literal com IVS/VS e literal inválido (0 ou 2+ code points). Widget/prints de Ajustes: export, restore ok, restore recusado (mensagem visível), seção Sobre / Fontes com a atribuição, 390×844 e ≥900. Sem chave, token ou path pessoal no JSON de fixture nem nos prints. Seletor de arquivo: emulador, ou `n/a: sem emulador (#93)`.

## 6. Riscos

- **Cloud Vision (custo e chave).** Bake-off pior que manga-ocr; cada chamada paga. Chave mal guardada vaza. Mitigação na spec: toggle off por default, chave no armazenamento seguro do sistema (nunca Drift / F25 / log / print / repo), diálogo na primeira ligação, NF6. Q-N3 permanece aberta no PRD; Q8–Q11 e o limite diário no app estão **aprovados** (2026-11-04) em [`cloud-vision.md`](../specs/cloud-vision.md).
- **Desenho das bounding boxes (F22).** Muitas boxes numa página ~2 MP podem atrasar o overlay no telefone. Mitigação: medir no widget/emulador 390×844 antes do squash; se passar de NF2, reduzir trabalho no overlay no mesmo PR, sem mudar o contrato de `blocks`.
- **Backup JSON (F25).** Os cinco ACs da seção 4 (export, round-trip, schema antigo, `origin_page_id` órfão, schema desconhecido) mais restore atômico e `normalizeKanjiLiteral` em cada literal. Um restore que ignore esses aceites corrompe o Caderno ou perde kanji. Mitigação: testes de domínio nesses aceites **antes** do print; transação que aborta sem gravar nada; literal inválido não entra.
- **iOS / macOS com Mac offline.** Prints e parte da suíte dependem do worker Mac. A fila [#54](https://github.com/murilinhoPs/MangaJP/issues/54) não bloqueia o merge na nuvem; o item tem de existir **antes** do review (`n/a: Mac offline (#54)`; o link do comentário no corpo do PR é opcional).
