## Q-B1 recommendation

**Do not close Q-B1.** No measured engine is ≤ 10%.

**Working default (deferred, not wired to UI):** `manga_ocr` as a **sidecar** — it is the only engine with a real CER on this GT. Matches the PRD fallback of “Cloud/manga as default” on the manga side until Cloud Vision is scored.

Do **not** add `google_mlkit_text_recognition` to `pubspec.yaml` yet (breaks `flutter run -d linux`). Flutter `OcrEngine` stubs stay unimplemented.

### Why 20.75% (not a total OCR failure)

25/44 crops are **exact**, including `よぉ、相棒`, `千鶴屋？`, and long balloons such as `こんな人にご飯なんて作らなくっていいよ`.

Two buckets dominate the 110 edits:

1. **`page_0_b1` (52 edits)** — red multi-column cover overlay on dark art, not a speech balloon. manga-ocr hallucinated a plausible sentence. Dropping this one crop would be 58/469 = **12.37%** (still above 10%). That is diagnostic only; the official number includes it.
2. **manga-ocr `post_process`** — the library maps `…` (U+2026) → `...` then `jaconv.h2z` → `．．．` (U+FF0E × 3). Under glyph-as-drawn CER that is a real error (`痛い…` vs `痛い．．．` is 3 edits on a 3-char GT). About **42** of 110 edits are this expansion. Collapsing those dots for diagnosis only → **12.83%**, still above 10%. The bake-off does **not** apply that collapse to the official score.

Remaining true substitutions are small (`お母ちんだ`, extra `しかし`, `ー` vs `――`, dropped `「」`, `いっへん`/`いっぺん`).

## Plan to close Q-B1

1. **Cloud Vision** on the **same** 44 PNGs:
   `CLOUD_VISION_API_KEY=… python3 tools/cer_bakeoff/bakeoff.py --gt-dir <gt> --engines cloud_vision`
   (`DOCUMENT_TEXT_DETECTION`, `languageHints: ["ja"]`). Merge `results/`. This is the highest-leverage skipped engine (overlay + punctuation).
2. **ML Kit JP** on a device/emulator: `TextRecognizer(script: TextRecognitionScript.japanese)` → JSON dump → `--predictions mlkit_ja=dump.json`. Needed before choosing an on-device default.
3. If Cloud/ML Kit still miss 10%, keep **manga-ocr sidecar** as working default and consider an **engine-side** inverse of manga-ocr’s ellipsis `post_process` (`．．．` → `…`) — that is not CER folding; it is undoing library output. Re-score. Product OCR is balloon crops; cover overlays like `page_0_b1` may need a tighter crop, not a different engine.

Q-B1 closes when a measured corpus CER on this GT is ≤ 10%, or when Cloud + ML Kit are measured and we explicitly accept a working default above 10%.
